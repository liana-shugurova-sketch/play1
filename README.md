# 🎮 Угадай слово

Интерактивная веб-игра на React, где нужно составлять слова из набора букв. Простые, бытовые слова, которые часто используются в жизни.

![React](https://img.shields.io/badge/React-18-blue?logo=react)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?logo=typescript)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-4-blue?logo=tailwindcss)
![Vite](https://img.shields.io/badge/Vite-6-purple?logo=vite)

## 🎯 Особенности

- **7 уровней** с простыми бытовыми словами (ШКОЛА, ДОМИК, КАРТА, КОРОВА, МАСКА, МОЛОКО, РАДИО)
- **3 типа подсказок** с разной стоимостью:
  - 💡 **Буква** (-10 очков) — показывает первую букву ненайденного слова
  - 🔢 **Длина** (-5 очков) — показывает длину ненайденного слова
  - ✨ **Плитки** (-15 очков) — подсвечивает плитки для составления слова
- **Система очков** с бонусами за серии правильных ответов
- **Штрафы за подсказки** — если использовал подсказку для слова, очки за него снижаются
- **Поддержка клавиатуры** — можно играть мышкой или клавиатурой
- **Адаптивный дизайн** — работает на мобильных и десктопах
- **Анимации** — 3D куб, плавные переходы, эффекты подсказок

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена

```bash
npm run build
```

### Предпросмотр продакшен-сборки

```bash
npm run preview
```

## 🎮 Как играть

1. **Собирай слова** — кликай по буквам или используй клавиатуру
2. **Проверяй** — нажми "Проверить" или Enter (минимум 3 буквы)
3. **Используй подсказки** — если застрял, но помни про штрафы!
4. **Найди все слова** — переходи на следующий уровень

### Управление клавиатурой

- **Буквы** — выбрать плитку с соответствующей буквой
- **Enter** — проверить слово
- **Backspace** — удалить последнюю букву
- **Escape** — очистить поле
